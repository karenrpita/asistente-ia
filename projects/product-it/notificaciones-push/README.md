# Nuevo sistema de notificaciones Push

**Estado:** GNP redactado, pendiente de estimación de IT
**Última actualización:** 2026-10-17
**Alcance:** APP (iOS y Android)

---

## Descripción

Sustituir la herramienta in-house antigua de push por un sistema nuevo. Permitirá enviar push segmentadas por edición (MARCA España, MARCA USA, MARCA English y MARCA México) desde una misma app, con rich push (texto, imagen, GIF), deep links internos y externos, envío programado según la zona horaria de cada edición y alertas automáticas de goles y resultado final. Incluye un dashboard de envío, recepción, apertura y tráfico generado, con histórico en Looker Studio. Se plantea como desarrollo propio del equipo de Aplicaciones de IT.
