# Top Scroll

**Estado:** En evaluación — prueba realizada, compromete CLS
**Última actualización:** 2026-04-16

## Descripción

Nuevo formato publicitario Top Scroll. Se muestra en la parte superior del scroll de la página.

## Prueba realizada (abril 2026)

- Prueba ejecutada en la sección de Ajedrez.
- **Resultado:** la prueba compromete el CLS (Cumulative Layout Shift), métrica de Core Web Vitals.
- Pendiente decisión sobre si se activa, se descarta o se reformula técnicamente para no impactar CLS.

## Riesgo

Activar este formato con CLS elevado penaliza el posicionamiento SEO y la valoración de la página por parte de Google. No debe activarse sin resolver el impacto en CLS.
